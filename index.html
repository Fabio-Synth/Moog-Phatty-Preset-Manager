Phatty Preset Manager

SysEx preset manager & librarian for Moog Little Phatty and Slim Phatty — backup, browse and restore patches

Starting MIDI…

Model tags every recording, and prevents a Little Phatty dump from being sent to a Slim Phatty (and vice versa). It is set automatically when the port name contains “Slim” or “Little”.

MIDI In is the port the synth sends its data to; MIDI Out is the port used to send data back to the synth.

On Windows the Slim Phatty often appears as “USB Audio Device”: choose it manually once and it will be remembered.

On the synth, open MASTER → MIDI SETUP and make sure MIDI Input and MIDI Output are set to USB or DIN/USB (factory default), and that the MIDI channels are not OFF.

Uses Web MIDI: works in Chrome, Edge, Opera or Brave (desktop and Android), and in Firefox on desktop. Safari doesn't support Web MIDI yet.

Exact copies only. This tool never edits or creates preset data: it only records dumps sent by your synth and replays them unchanged.

Presets travel as MIDI System Exclusive (SysEx) messages. The same channel is used by firmware updates, so this page applies strict limits:

  • Only messages with the Moog manufacturer ID and a valid SysEx structure are accepted.
  • Anything larger than 64 KB is rejected. A complete bank is roughly 17 KB.
  • A recording is classified as “Single preset” or “Full bank” by its size. Anything else is stored as “Unclassified” and can never be sent.
  • Before every send, the data is checked again (CRC32 and structure).
  • Sending is locked by default, needs explicit confirmations, and locks itself again after each send.

Recording is passive: nothing is written to the synth while you record. Only “Send to synth” writes to its memory.

1

Record from synth (Save)

The transfer is always started from the synth; this page listens and stores what arrives.

  1. Press MASTER, then CURSOR to highlight the SYSEX menu items.
  2. Turn VALUE to SEND CURRENT PRESET (one preset), or to SEND ALL PRESETS or BULK DUMP for the whole bank — either works here.
  3. Click the matching button here.
  4. Press ENTER on the synth and wait: a bank takes a few seconds.

“Single preset” saves only the preset currently selected on the synth. To back up several presets, either repeat the procedure for each one or record the full bank once.

The synth's SysEx menu actually offers three distinct commands: SEND CURRENT PRESET, SEND ALL PRESETS and BULK DUMP. The first is a single preset; the other two both send the complete bank (BULK DUMP also includes global and performance settings) — “Record full bank” accepts either one.

If a recording is rejected because of its size, the reason is shown in the status bar.

Library (Load)

Recordings are stored in this browser. Use Download to keep a file (.syx) that you can also open in SysEx Librarian or MIDI-OX. Import accepts .syx files, including the factory banks published by Moog.

Click a name to rename it. Deleting an entry does not delete files you have downloaded.

CRC32 is a fingerprint of the data. It is recalculated before every send to make sure the stored copy is intact.

Compare: tick two entries and press Compare selected to see whether they are identical byte for byte. Typical uses:

  • Check a restore: send a preset, record it again from the synth, then compare the two.
  • Check that two backups of the bank are the same, meaning nothing changed in between.
  • See at which byte positions two recordings differ.

Entries marked Unclassified are archived but cannot be sent.
